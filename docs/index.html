Установка и запуск

Windows
TTS_Lite_Windows.zip → распаковать → TTS_Lite.exe
Linux
tar -xzf TTS_Lite_Linux.tar.gz && ./TTS_Lite/TTS_Lite
macOS
tar -xzf TTS_Lite_macOS.tar.gz && open TTS_Lite.app

Из исходников: pip install -r requirements.txt && python main.py · Сборка: pyinstaller build.spec · Тесты: pytest -q (177 passed)

Приватность и лицензии
